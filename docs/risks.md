## 1. 高影响

### R1 Note 11 真课只有 1 个完整视频（AC06 结论已由 13 节真实素材覆盖，本项仅剩单机证据偏弱）
- 影响：Note 11 上的真实素材样本仅 1 节，其余 7 节为合成样本；Note 11 单机不能代表真实多节课程。**AC06 已通过**：Note 12T Pro 13 节真实 MP3（导入/排序/去重/进度保留）+ Note 11 失效标记与恢复（改名校验），故本项不再作为 AC06 缺口。
- 触发：`/Users/zzymima0000/Documents/1第一章：家庭与朋友` 只有 1 个完整视频 `5.Bonus Time - No legs or arms.mp4`（54.149s，1080x2344，H.264+AAC，49,677,154 B）；另 5 个 `.baiduyun.p.downloading`（约 678M/616M/614M/842M/494M）是百度网盘未下完临时文件，不可播放。
- 处置：若用户补齐下载，可另做 Note 11 真实多节复测；在此之前引用 AC06 结论须写明证据来自 Note 12T Pro 13 节与 Note 11 改名校验。

### R2 AC08 到点矩阵只完成 8/10
- 影响：前台/后台/锁屏的按秒到点与通知到达率没有统计结论，OEM 省电/勿扰下可能延迟或静默。
- 触发：只凭前台 2 / 后台 2 / 锁屏 4（共 8 轮）就宣布到点可靠。
- 处置：按前台/后台/锁屏各 10 轮补齐，记录每次延迟与失败数；报告里固定写「8/10」，不得写全通过。

### R6 锁屏提醒依赖系统「发声权限 / 锁屏通知」开启
- 影响：系统发声权限（或锁屏通知权限）关闭时，锁屏到点画面不出现、只剩震动，用户看不到「哪节课结束/该切换了」。
- 触发：14:39 发声权限关闭时，锁屏亮屏截图 `build/qa/100-lockscreen-notification.png` 只见媒体与 USB 通知；14:50 在 MIUI「设置 → 碎片时间 通知」打开发声权限后，`build/qa/104-lock-alert-visible.png` **清楚显示「时间到了 / 「Test10」00:10 已到」**，`dumpsys audio` 同时有 `MediaPlayer usage=USAGE_ALARM state:started`。
- 处置：Note 11 已验证**开启后可见**（锁屏可见性记 PASS，前提＝发声权限与锁屏通知开启）；交付/验收说明须写清该前提，权限被拒场景仍未测，不得写「无条件可见」。

### R3 debug 签名，不可作为发布包
- 影响：不能上架或正式分发；升级/覆盖安装受签名策略约束。
- 触发：把 debug APK 当正式版交付或换机安装。
- 处置：发布前生成正式签名并登记版本台账；当前 0.1.9 仅侧载内测。

## 2. 中影响

### R4 备份 JSON 只能证明导出与设备内往返，系统 UI 导入未测
- 影响：用户换机/恢复时可能选不到文件或导入失败，而文档看起来「备份已通过」。
- 触发：只引用 `BackupRoundTripTest` PASS 或导出的 `fragment-time-backup-20261111.json`（8,535 B）就认定为导入链路可用。
- 处置：补「系统文件选择器选 JSON → 导入 → 数据回读」真机用例；在此之前写作「导出 PASS / UI 导入未测」。

### R5 AC09 已修复，但其余中断场景未验证
- 影响：来电、耳机拔出、系统重启后的断点恢复与提示仍无证据，用户可能误以为仍在学习或断点丢失。
- 触发：把 AC09 的强停首屏横幅 PASS 外推到所有中断场景。
- 处置：强停/杀进程链路已由 0.1.8 根级横幅真机 PASS、0.1.9 继承；来电、耳机拔出、系统重启恢复另列未测，补测前不得写全项 PASS。

- **锁屏提醒可见性**：14:50 开启系统发声权限后已可见且有闹钟音（`build/qa/104-lock-alert-visible.png`、`USAGE_ALARM state:started`）；14:39 的不可见对应发声权限关闭状态。内容见 §1「R6」，此处只留指针。

### R7 OEM 省电 / 勿扰 / 通知默认为忽略
- 影响：到点提醒延迟或静默，甚至进程被杀导致计时中断。
- 触发：MIUI/OPPO 省电策略、勿扰模式、新装应用通知默认「忽略」。
- 处置：Note 11 通知已可用、精确闹钟在 Android 11 无需权限；OPPO 实测默认忽略通知已手动打开；勿扰与省电专项未测，不得承诺 100% 按秒到点。

### R8 MIUI 文件选择器文件卡/文件夹卡对 `input tap` 无响应
- 影响：自动化验收会在 SAF 目录选择与备份 JSON 选择处假失败（按钮与滑动正常，卡片不响应），被误记成产品缺陷。
- 触发：用裸 `adb shell input tap` 点 DocumentsUI 文件夹卡片或文件卡片。
- 处置：改用 UiAutomator 无障碍 `ACTION_CLICK`（`PickFolderTest` 已成功完成目录选择）；测试 APK 用完卸载，避免双进程干扰。此条属测试通道限制，不是 App 缺陷。

### R9 双机证据不完整（AC11）
- 影响：OPPO PLG110 仍为 0.1.0，最终 0.1.9 只在 Note 11 5G 验证，双机一致性无证据。
- 触发：用 0.1.0 的 OPPO 结果代表 0.1.9。
- 处置：发布前在 OPPO 覆盖安装 0.1.9 并补原始证据，或由用户明确接受单机验收。
