## 1. 产品目标和载体决策

用户在刷牙（默认 2 分钟）、滴眼药水（默认 3 分钟）等日常短时场景，点一下“开始”，立即从上次位置播放英语视频或 MP3，同时倒计时；到点铃声/震动/通知提醒，暂停媒体并保存进度。下次无论选哪个场景，都接着上次课程学习。

**冻结载体：独立 Android APK**，优先 Kotlin + Jetpack Compose + AndroidX Media3 / MediaSessionService。原因：要求可靠的原生后台音频、锁屏、通知与精确闹钟体验。HTML/PWA 仅作交互原型，不能代替原生后台与真机验收。只做 Android，不同时开发 iOS。原生方案后续做 iOS 需要单独适配。

V1 必须完全离线；Mac mini 不需要在线，手机不依赖 Wi-Fi、5G、Tailscale、浏览器、云账号、服务器、Docker、Supabase 或 AI Key。对个人学习素材只做本人授权的本地读取和复制，不公开内容。

## 2. 实际课程来源与真实样本预检

Mac 外接三星盘的只读课程来源：
/Volumes/三星/H-DL-OB笔记/003祖成英语90天陪练168节课程/3-场景实战课【105节】

目前只确认用户给出的路径，**本轮 Mac 项目读取器尚未进入外接盘执行真实扫描**。开发者在本机 M0 必须核查目录是否挂载/可读，递归统计视频和音频的真实数量、名称、大小、总容量、容器、编码、是否存在音轨、时长、编号排序、损坏和重复。不得推断所有 105 节均是 MP4 且可解码。

先选代表性的 **5–10 节真实课程**做开发和机型验证，包括长视频、跨编号的课程与至少 1 个异常样本；MP3 初期可使用开发者合法样本测试格式能力，用户没有指定实际 MP3 文件。检查文件时只读，不移动、删除、改名或转码原件，课程/清单/机内私有路径不可提交 Git 或公开发布。

### 最短导入路径

1. Mac 通过 USB 文件传输或已经授权的 ADB，复制 5–10 节到手机的独立子目录（可使用 Movies/FragmentLearning），先检查手机剩余存储和复制完整性；**不是让手机远程读 Mac 的 /Volumes/ 路径**。
2. APK 使用 Android 系统文件夹选择器 ACTION_OPEN_DOCUMENT_TREE 申请所选子目录的持久化访问，使用 ContentResolver/DocumentFile 建索引；不申请“所有文件访问”，不依赖 Android 11+ 受限制的根目录或 Downloads 根目录授权。
3. 默认直接读取用户已复制到手机的媒体，不再二次复制占空间；按文件数字自然排序，同名冲突/无效编码显示清晰提示。
4. 新课程加入后选择“更新课程目录”，增量扫描并保留旧课进度。文件删除、移动、替换或目录授权撤回时显示“重新关联”，不可静默错配到别的课程。
5. USB 断开、Mac 关机、Wi-Fi 和移动数据都关闭后，APK 仍能冷启动、播放、计时和提醒。未来局域网自动同步不是 V1 前置条件。

## 3. 页面信息架构与交互

### 首页（最高优先级）

首屏无需滚动就能看到：
- 两个场景卡：“刷牙 02:00 [开始]”“滴眼药水 03:00 [开始]”，一键启动，不先进入详情。
- 简洁“+新增场景”；已有场景可编辑名称/时长/删除（确认或撤销），重启仍记忆。
- 当前课程名称、上一回的播放点和可用/缺失状态。没有导入课时展示“导入课程”或“仅倒计时”。
- 控件不占整行无意义空白；不在每个 Tab 页面重复放跨 Tab 导航卡。

建议最多三处一级目的地：“计时”“课程”“设置”，或者首页+课程抽屉+设置；**不机械制造 4–5 个底部 Tab**。不得让高级课程设置、图表、介绍长文占据最重要首屏。

### 计时进行中

- 大号剩余时间 + 场景名 + 当前课名/播放进度紧凑展示；有视频时可展开/收起画面，音频时显示基本信息。
- 主要操作：“暂停/继续计时”“提前结束”；播放器单独可播放/暂停、上一/下一课、拖动、快退/快进，适度提供倍速。
- **暂停计时**：同时暂停媒体、冻结剩余时间，并撤销到点闹钟；继续时二者同步恢复。
- **仅暂停播放器**：倒计时继续，不能误当“已听英语”，时间记账分别累计。
- 换课、拖动进度、调整音量不重置倒计时；一节自然播放完自动下一节，不重置剩余时长。
- 提前结束：确认后保存真实学习进度与已用时间，不虚报完成；到点默认不自动开启第二轮。

### 课程页

展示真实导入列表、课序、已学位置；可直接选课、从头开始或“从上次位置继续”、手动设置起播点、重新扫描目录。所有场景默认共享同一队列与断点（刷牙 → 滴眼药水 → 刷牙连续播放）；每个场景独立关联课程列表是 P1 扩展，不能破坏默认共同进度。

### 设置

播放与提醒（试听铃声、测试震动、检查系统通知/精确闹钟、说明勿扰/省电限制）；课程来源与失效重关联；外观（默认浅色、深色、跟随系统，重启保持、墨水屏高对比）；备份与恢复（JSON 仅保存场景、列表索引、进度和必要的使用记录，不打包媒体文件）。

### UI 模板依据（已读取中央设计管家 V1.1.0）

- TPL-12 A：训练/计时播放器，继承大号倒计时与暂停/恢复动作；**锁屏后台仍要在新 APK 重新验证**。
- TPL-04 A：设置页分组，旧 P053 截图存在版本证据差异，只取交互原则。
- TPL-21 A：浅色、深色、系统主题及持久化、全局颜色语义。
- TPL-22 B：空白、媒体失效、权限拒绝时给一句人话和可执行恢复动作。

首屏字号、按钮宽度、单手操作需针对 Redmi 和 OPPO 真机验证；常用按钮触控区建议不低于 48dp，用户文案避免 FR/AC/Gate/Task 等工程术语。

## 4. 核心状态机和技术实现

### 一键启动

点击 [开始] 即刻视觉/震动反馈，进入 PREPARING；本地媒体开始**实际播放**后再启动倒计时（避免解码/缓冲时间吞掉学习时间）。若媒体缺失、无权限、不支持格式等，提示“换课程/重新关联/仅倒计时”而不是假装播放成功。禁止同一时刻多个活动会话或多重音频叠加。

### 倒计时

使用 SystemClock.elapsedRealtime() 等单调时钟计算截止时间；保存 sessionId、开始时刻、deadline、剩余时长、状态，UI 的 1 秒刷新不能当时间源。后台/锁屏依然根据真实时钟计算。暂停时取消旧闹钟，恢复时重排。系统强制停止/重启后不可假装媒体仍播放，回到 App 说明被中断及真实经过时间。

### 音视频

媒体引擎建议 Media3 ExoPlayer + MediaSession/MediaSessionService，后台播放使用合适的 mediaPlayback 服务类型和媒体通知/系统控制。支持 MP3/M4A/WAV/主流 MP4，**具体能否解码以真实文件验证**。MP4 有音轨时锁屏继续听声音、解锁恢复画面；无音轨时明确提示不能听。遵循音频焦点，来电、拔耳机、蓝牙断连或其他 App 抢焦点时避免悄悄大声自动恢复。媒体暂停不等于计时暂停。

### 到点提醒和唯一性

到期统一执行：暂停媒体 → 保存播放点 → 将本次 session 标记已完成 → 生成一次到点提醒。媒体服务/计时服务与 AlarmManager 兜底共享 sessionId 去重，避免双重响铃、重试不断提醒。提醒通知与英语媒体通知分为独立渠道，正确处理媒体音量为 0、闹钟音量、震动、锁屏通知、勿扰和静音。Android 12+/14+ 的 SCHEDULE_EXACT_ALARM 须按当前权限状态判断并合法引导；权限拒绝提供明确降级提醒，不滥用 USE_EXACT_ALARM。任何系统强制停止/OEM 省电/勿扰下都**不能承诺 100% 按秒到点**。

复用 P068 的后台提醒历史教训：R14 曾出现“计时准但无可察觉铃声”，随后以高重要性提醒渠道、闹钟音频属性和去重机制修复；R15 的锁屏通知可见性未定位。新项目必须做独立真机专项，不把 P068 的 PASS 当作新 APK 通过。

### 进度和数据

简化模型：Preset(id,name,durationSec)，Playlist(id,orderedMediaIds)，Course(id,title,uri,durationMs,type,fingerprint,status)，PlaybackCheckpoint(playlistId,courseId,positionMs,speed,updatedAt)，TimerSession(id,presetId,targetSec,elapsedSec,actualMediaSec,state,alerted)，Settings(theme,alarm,vibration)。

本机 Room/DataStore 持久化；播放中每约 3–5 秒节流写断点，暂停、切课、到点、退出时立即写。手机重启恢复到最近已落盘位置但不自动开播；仅课程真正播完才标“本节完成”。如果 URI 与文件指纹不匹配，禁止自动对应另一节。

JSON 导出/导入必须可复原场景、课程元信息、播放位置、设置；不包含媒体。覆盖前先保留恢复点，恢复后如媒体缺失引导重新授权/关联。首次版不需要云数据库，也不提供跨机自动同步。

## 5. 开发范围分级

**P0（必须完成的真实闭环）**：场景创建/编辑/删除；点击开始→播放音轨→倒计时；锁屏后台有声播放；到点媒体暂停、保存并提醒一次；默认所有场景共享断点；导入本地文件夹并增量更新；无网使用；本地设置和 JSON 恢复；最小首屏 UX；真机测试。

**P1（可在 P0 通过后追加，不阻塞首个可用闭环）**：0.75–2× 变速、快退/快进、轻量“今日实际学了几分钟”、单场景不同队列、课程列表较完整管理。

**禁止擅加**：AI、账号、在线云同步、复杂统计图表、社交、会员、网络自动抓取、Mac 长驻服务、再次复制课程造成双份占用；不要给 P068 增加新 Tab，不修改 P040/P051/P067 源项目。此产品是**手动启动的分钟计时器**，不是每天几点提醒滴眼药水的医学用药计划；用户设定的 3 分钟不是医疗建议。
